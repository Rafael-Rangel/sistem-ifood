# Icare Finance

Painel de gestão para restaurante parceiro (FIAP / iFood), agora funcional no GitHub Pages e na Vercel.

## Acessar

- GitHub Pages: https://rafael-rangel.github.io/sistem-ifood/
- Login demo: `rafael@icare.finance`
- Senha: `ifood2024`

## O que funciona

- Login, cadastro, sessão e logout
- Dashboard com gráficos reais dos pedidos
- Filtros, conclusão e cancelamento de pedidos
- Rankings de clientes, entregadores e pratos
- CRUD de usuários e permissões
- Chat com envio de mensagens
- Layout mobile (menu, barra inferior, tabelas e cards)
- Animações com GSAP

Não precisa de Live Server. Qualquer servidor estático serve.
